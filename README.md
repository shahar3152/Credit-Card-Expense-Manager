## Credit Card Expense Manager – Client-Side Final Project

This project is a **web-based application for managing credit card expenses**, built using **HTML, CSS, and JavaScript**.  
The system provides users with an intuitive interface to track spending, manage budgets, and receive personalized recommendations.

### 🌐 Features
- **Authentication:** Login and registration pages for secure user access.
- **Dashboard:** Overview of user financial data, recent transactions, and budget summaries.
- **My Charges:** View and manage individual credit card charges.
- **Actions Upload:** Users can upload files containing their transaction history.
- **Budget Tracking:** Plan and monitor monthly budgets.
- **Recurring Expenses:** Manage recurring payments.
- **Recommendations:** Personalized spending advice via API integration.
- **Responsive Design:** Works seamlessly on mobile, tablet, and desktop devices.

### 🔹 Technical Highlights
- **Front-End:** HTML5, CSS3, JavaScript for interactive UI.  
- **File Handling:** Users can upload transaction files to update their data.  
- **API Integration:** Recommendations screen fetches personalized suggestions from an external API.  
- **Responsive Design:** Flexbox, CSS Grid, and media queries ensure accessibility on all devices.  
- **User-Friendly Interface:** Clean navigation and intuitive layout for improved UX.

### 💡 Key Learning Outcomes
- Building interactive web applications with multiple screens.  
- Handling file uploads and dynamic data rendering.  
- Integrating APIs for personalized recommendations.  
- Designing responsive layouts for various screen sizes.
